What it does

Everything happens on your Following page, inside your own browser. Nothing is unfollowed until you approve the list.

Preview before anything happens
Scan your newest or oldest follows, see every account it picked, and untick the ones you want to keep.
Keeps people who follow you back
Anyone showing "Follows you" is skipped automatically. You can turn this off.
Finds inactive accounts
Only pick accounts that haven't posted in 3, 5 or 6 months, or have never posted.
Slow, human-like pacing
Random 30–60 second gaps, short breaks, hourly batches and a daily limit you set.
Never-unfollow list
Add friends and favourite accounts once, and add keywords to keep accounts by name or bio.
Full history
See everyone it unfollowed, with links to follow them again if you change your mind.

Install in 5 minutes

Pick your device. You only do this once.

  1. Get the Userscripts app

    Free on the App Store, by Justin Wasack. Open it once and tap Set Userscripts Directory, then choose its Userscripts folder.

  2. Switch it on in Safari

    Settings, then Apps, then Safari, then Extensions, then Userscripts. Turn it on and set websites to Allow.

  3. Install the script

    In Safari, tap the button below. On the page that opens, tap the page menu (left of the address bar), then Userscripts, then Install.

    Install script
  4. Open your Following page

    Go to x.com in Safari (not the X app), open your profile and tap Following. Tap the 🧹 button at the bottom left.

iPhone pauses web pages you're not looking at, so keep Safari open on screen while it runs. The tool keeps your screen awake, and if you leave, it continues where it stopped when you come back.

  1. Get Firefox

    Free on the Play Store. Chrome on Android can't run add-ons.

  2. Add Tampermonkey

    In Firefox, open the menu, then Extensions (Add-ons), find Tampermonkey and tap Add.

  3. Install the script

    Open this page in Firefox and tap the button below, then tap Install on the Tampermonkey page.

    Install script
  4. Open your Following page

    Go to x.com in Firefox, open your profile and tap Following. Tap the 🧹 button at the bottom left.

Use split screen or a pop-up window to keep Firefox visible while you use other apps, and set Firefox's battery use to Unrestricted in your phone's settings.

Stay safe

X doesn't publish an official unfollow limit, so the tool is set up to go slowly.

  • ≤150unfollows a day is the safer range. Start at 50 for the first days, especially on newer accounts.
  • ≈35an hour, in batches with random gaps and breaks, so it doesn't look automated.
  • 24hpause if X ever shows a warning. The tool stops by itself when it sees one.

Automating actions goes against X's rules, and X decides what happens to accounts, so use it at your own risk. The tool never sees your password and only runs inside your own browser.
