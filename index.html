How it works

Scan. Review. Sweep.

Everything runs inside your own browser, on your own X account. It only ever talks to X itself.

Scan your follows

Start from your newest or oldest follows. Pick all accounts, or only ones inactive for 3, 5 or 6+ months.

Review the list

See every account it picked. Untick anyone you want to keep. Nothing is unfollowed until you say so.

Let it sweep

Choose the speed, how many per hour and per day, and break length. Watch it work through the list.

What you get

Small tool, careful by design.

🤝Keeps your mutuals

Anyone who follows you back is skipped automatically.

💤Finds inactive accounts

Checks when each account last posted, and remembers results for 7 days.

⏱️Your pace, your limits

Safe to fastest speed, hourly and daily caps, and breaks between batches.

🛑Stops on warnings

If X ever shows a warning, it stops by itself and waits 24 hours.

📝Never-unfollow list

Protect friends by username, or keep accounts by words in their name or bio.

↩️Full history

Every unfollow is logged with a link, so you can follow anyone again.

Before you start

Keep the screen on while it runs.

Phones pause web pages you're not looking at. It doesn't lose anything, it just waits until you come back.

  • iPhoneLeave Safari open on the X tab and set Auto-Lock to Never while it runs. Plug in and leave it face up.
  • AndroidUse split screen or a pop-up window so Firefox stays visible while you use other apps.
  • ComputerRuns in a background tab while you do anything else. Turn off Chrome's Memory Saver for x.com.
  • Signing inYou only sign in to x.com itself, in the same browser. The tool never sees or asks for your password.

Install

Ready in 5 minutes.

Pick your device. You only do this once, and updates arrive by themselves.

  1. Get the Userscripts app

    Free on the App Store, by Justin Wasack. Open it once and tap Set Userscripts Directory.

  2. Switch it on in Safari

    Settings, then Apps, then Safari, then Extensions, then Userscripts. Turn it on and allow all websites.

  3. Install the script

    Tap the button below in Safari. On the code page, tap the page menu left of the address bar, then Userscripts, then Tap to install.

    Install script
  4. Sweep

    Open x.com in Safari (not the X app), sign in, go to your profile, tap Following, then tap 🧹.

    Firefox menu, then Extensions, find Tampermonkey and tap Add.

  3. Install the script

Questions

Good to know.

Does it need my X password?

No. You sign in on x.com like normal, and the tool works inside that page. It never sees your password, and the only place it sends anything is X itself.

Is it safe for my account?

It's built to go slowly, with limits and breaks, and it stops if X shows a warning. Automation can still go against X's rules, so start with around 50 a day and raise it slowly.

Why do I need to keep the screen on?

Phones pause web pages in the background to save battery. The tool saves its place, so when you return it continues where it stopped.

Does it work in the X app?

No, it runs in the browser: Safari on iPhone, Firefox on Android, or any desktop browser with Tampermonkey.

Can I undo an unfollow?

Open Unfollow history in the panel. Every account has a link, so you can open it and follow again.

Is it really free?

Yes. There's an optional tip button if it saves you time.
